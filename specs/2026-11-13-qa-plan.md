## Environments

- **Fake Google** (`KURVIQ_FAKE_GOOGLE=1`, `wrangler dev`, see `CLAUDE.md` and `scenes-plugin/test/e2e`): several
  test accounts at once (owner, editor, commenter, viewer, a domain colleague, an outsider); everything that needs
  more than one person, permissions or failures (fault injection).
- **kurviq.com** (production, real Google): what the fake can't show (Drive's thumbnail and search, Google's
  picker, real OAuth, Supabase). Steps that need Fabian's Google accounts or Supabase are marked **(with Fabian)**;
  the QA agent prepares them and asks.
- **Local install** (`npm start`, https://draw.test): agents through the local MCP, PDF export, the https move.
- Tools: Playwright (browser), the Kurviq MCP tools (agent paths), the unit tests
  (`excalidraw/node_modules/.bin/vitest run --config scenes-plugin/test/vitest.config.mts`), the e2e scripts
  (`scenes-plugin/test/e2e/*.mjs`, `online/test/live-server.mjs`), SonarCloud's API (zero issues).

## Regression baseline (features before this project)

Scenes: create, rename, delete, open by link, local-only, Drive sync (push, pull, merge, conflict), offline start.
Slides: template, slides, notes, presenter view, PDF export, thumbnails in the sidebar. Formatted text, tooltips,
custom fonts, text padding. Sharing: share panel ("Add people" opens Drive), general access, short links, shared
folders (new design), "Shared with you…", scene links finding shared scenes, the link hint. Comments (pins,
threads, mentions, resolve, edit, remove, links). Agents: read_scene, edit_scene (elements, format, comments),
view_scene, save_scene, create_view, list_scenes, app_status. The scene pill (pen, cloud, lock), the wheel zoom
(mouse zooms, trackpad pans), the font size field gone from the panel. Statistics counters, feedback, contact.

## Result format

Per criterion: **pass** / **fail** / **blocked** (with why), the evidence (screenshot path, tool output, test
name), and for a fail the steps to reproduce. Failures are fixed and re-checked before the project counts as done.

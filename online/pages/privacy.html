Privacy / Datenschutz

Last updated / Stand: 25 October 2026 · Deutsche Fassung unten

In short: Kurviq has no accounts, no analytics and no tracking. Your drawings stay in your browser. Kurviq's server stores nothing about you, except feedback you choose to send. Data only goes elsewhere when you choose it: GitHub, if you connect it, and your AI agent, if you give it your agent link.

Hosting (Cloudflare)

Kurviq runs on Cloudflare (Cloudflare, Inc., 101 Townsend St, San Francisco, CA 94107, USA). To deliver the website, Cloudflare necessarily processes your IP address and technical request data (e.g. browser, requested page, time). We do not keep request logs. Cloudflare may process data in the USA; Cloudflare is certified under the EU-U.S. Data Privacy Framework. Legal basis: Art. 6(1)(f) GDPR (our legitimate interest in a secure, working website).

Your drawings and settings

Scenes, settings and (if you create one) your agent link are stored in your browser (localStorage, IndexedDB). They are not sent to us. You can delete them at any time by clearing this site's data in your browser. Kurviq loads no third-party scripts, fonts or images; your browser only talks to kurviq.com (and to GitHub, see below).

GitHub (optional)

Only if you click "Connect GitHub": you are sent to GitHub (GitHub, Inc., 88 Colin P. Kelly Jr. St, San Francisco, CA 94107, USA; certified under the EU-U.S. Data Privacy Framework) to sign in and allow the Kurviq GitHub App. Kurviq then sets an encrypted, httpOnly cookie kq_github with your GitHub access tokens and username, so the connection stays in this browser (up to 6 months, renewed when you use Kurviq), plus a short-lived cookie kq_oauth_state (15 minutes) that protects the sign-in. Both are technically necessary for the feature you asked for; no consent banner is needed. Your browser then reads and writes your scenes in the repository you chose directly with GitHub's API. Kurviq's server only exchanges and refreshes the tokens and stores nothing. Legal basis: Art. 6(1)(b) GDPR (providing the feature you request). To end it: "Disconnect" in Kurviq (this also revokes the token), or revoke Kurviq in your GitHub settings under Applications. GitHub's privacy statement applies to your GitHub account.

Shared and public scenes (optional)

A scene link (kurviq.com/@owner/scene) contains nothing but the GitHub account and the scene name. Private scenes are read by the visitor's browser directly from GitHub, with the visitor's own GitHub access; Kurviq's server is not involved. When you make a scene public, it moves to your public GitHub repository kurviq-public: anyone can see it there, and it stays in that repository's git history even if you make it private again. Kurviq's server passes public scenes on to viewers and Cloudflare keeps a copy in its cache for about a minute; nothing else is stored.

Fonts from Google Fonts (optional)

When you add a font from Google Fonts, Kurviq's server fetches it from Google (and Cloudflare caches it for a day); your browser only talks to kurviq.com, so Google doesn't see you. The font is stored in the scenes that use it.

AI agents (optional)

Only if you create an agent link (MCP button) and give it to an AI agent: the agent's requests and your open Kurviq tab's answers (e.g. drawing content and images) pass through Kurviq's server on Cloudflare in transit. They are not stored. What the agent's provider does with the data is governed by that provider's terms. You can replace or switch off the link at any time.

Feedback (optional)

Only if you send a bug report or change request (Feedback link, or your AI agent sends one for you): Kurviq stores its kind, title and description, the name of the scene you had open, the time, and a keyed hash of your IP address (or of the agent link), used only to limit how many reports one sender can send per hour; the IP address itself is not stored. The reports are stored in a database at Cloudflare and read by us to decide what to build. Please don't put personal data in them. Legal basis: Art. 6(1)(f) GDPR (improving Kurviq). Write to us to have a report deleted.

Your rights

You have the right to access, rectification, erasure, restriction of processing, data portability and objection (Art. 15–21 GDPR), and the right to lodge a complaint with a supervisory authority, e.g. the Landesbeauftragte für den Datenschutz und für das Recht auf Akteneinsicht Brandenburg. As Kurviq's server stores no personal data, most of this is in your hands: clear the site data in your browser and disconnect GitHub. For anything else, write to us.

Datenschutz

Kurz gesagt: Kurviq hat keine Konten, keine Analyse und kein Tracking. Deine Zeichnungen bleiben in deinem Browser. Kurviqs Server speichert nichts über dich, außer Feedback, das du selbst sendest. Daten gehen nur dorthin, wo du es willst: zu GitHub, wenn du es verbindest, und zu deinem KI-Agenten, wenn du ihm deinen Agent-Link gibst.

GitHub (optional)

Nur wenn du auf „Connect GitHub" klickst: Du wirst zu GitHub geleitet (GitHub, Inc., 88 Colin P. Geteilte und öffentliche Szenen (optional)

Ein Szenen-Link (kurviq.com/@konto/szene) enthält nur das GitHub-Konto und den Namen der Szene. Private Szenen liest der Browser des Besuchers direkt bei GitHub, mit dessen eigenem GitHub-Zugang; Kurviqs Server ist daran nicht beteiligt. Machst du eine Szene öffentlich, wandert sie in dein öffentliches GitHub-Repository kurviq-public: Dort kann sie jeder sehen, und sie bleibt in dessen Git-Historie, auch wenn du sie wieder privat machst. Kurviqs Server reicht öffentliche Szenen an Betrachter weiter, Cloudflare hält dafür etwa eine Minute lang eine Kopie im Cache; sonst wird nichts gespeichert.

Schriften von Google Fonts (optional)

Fügst du eine Schrift von Google Fonts hinzu, lädt Kurviqs Server sie bei Google (Cloudflare hält sie einen Tag im Cache); dein Browser spricht nur mit kurviq.com, Google sieht dich also nicht. Die Schrift wird in den Szenen gespeichert, die sie nutzen.

KI-Agenten (optional)

Nur wenn du einen Agent-Link erstellst (MCP-Button) und ihn einem KI-Agenten gibst: Die Anfragen des Agenten und die Antworten deines offenen Kurviq-Tabs (z. B. Zeichnungsinhalte und Bilder) laufen auf dem Weg durch Kurviqs Server bei Cloudflare. Sie werden nicht gespeichert. Was der Anbieter des Agenten mit den Daten macht, regeln dessen Bedingungen. Du kannst den Link jederzeit ersetzen oder abschalten.

Feedback (optional)

Nur wenn du einen Fehlerbericht oder Änderungswunsch sendest (Link „Feedback“, oder dein KI-Agent sendet ihn für dich): Kurviq speichert Art, Titel und Beschreibung, den Namen der offenen Szene, den Zeitpunkt und einen verschlüsselten Hash deiner IP-Adresse (bzw. des Agent-Links), der nur dazu dient, die Zahl der Berichte pro Absender und Stunde zu begrenzen; die IP-Adresse selbst wird nicht gespeichert. Die Berichte liegen in einer Datenbank bei Cloudflare; wir lesen sie, um zu entscheiden, was wir bauen. Bitte keine personenbezogenen Daten hineinschreiben. Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (Verbesserung von Kurviq). Schreib uns, wenn ein Bericht gelöscht werden soll.
